## Typography & Layout

This theme is heavily inspired by Edward Tufte's document design principles. The main text column is narrower to improve readability, while the wide right margin is reserved for sidenotes, margin figures, and captions.

### Sidenotes

Sidenotes are a key feature of Tufte's design. They allow you to provide auxiliary information without breaking the flow of the main text.

You can create a numbered sidenote using standard Markdown footnote syntax. For example, here is a reference to a source [^1]. The note will appear in the right margin, aligned with the reference number in the text.

[^1]: This is a numbered sidenote generated from a standard Markdown footnote. It's perfect for citations or numbered commentary.

For unnumbered margin notes, use the `<Sidenote>` component:

<Sidenote>
  This is an unnumbered margin note. Use it for glosses, quick asides, or definitions that don't require a reference number.
</Sidenote>

On mobile screens, sidenotes are hidden by default and identified by a highlight color in the text; tapping the number or highlighted area reveals the note inline.

## Mathematics

We support beautiful math rendering using KaTeX.

### Inline Math
Inline math can be written by wrapping LaTeX equations in single dollar signs: $e^{i\pi} + 1 = 0$.

### Block Math
Block math is written using double dollar signs:

$$
\oint_{\partial \Sigma} \mathbf{E} \cdot d\mathbf{l} = -\frac{d}{dt} \iint_{\Sigma} \mathbf{B} \cdot d\mathbf{S}
$$

You can also use complex environments like `aligned`:

$$
\begin{aligned}
  \phi(x,y) &= \phi_x c_n(x,y) \\
  \psi(x,y) &= \psi_y c_n(x,y)
\end{aligned}
$$

## Figures

Figures in this theme are designed to be flexible and elegant. All figures support a "lightbox" feature—click any image to view it full-screen.

### Margin Figure
Small figures can be placed entirely in the margin using the `<MarginFigure>` component. These are great for small diagrams, portraits, or sparklines.

### Caption Below
If you prefer the caption to appear below the image (standard academic style) or if the caption is very short, use the `captionBelow` prop.

</Figure>





### Standard Figure (Margin Caption)
The default figure places the image in the main column and the caption in the side margin. This keeps the vertical flow uninterrupted.

<Figure id="fig-standard" caption="A standard figure with the caption placed in the margin. This allows for long, descriptive captions that don't clutter the main text flow.">
  ![Abstract geometric shapes](/images/abstract-shapes.png)
</Figure>

### Full-Width Figure
For large, detailed images, use the `fullWidth` prop. These figures span the entire width of the page (content + margin).

## Print & PDF

Each article has a high-quality PDF version available, designed using Tufte-style typography for print. The PDF versions are generated at build time using a headless browser, ensuring they match the web styling exactly.

### Accessing the PDF

You can access the PDF version of any article in two ways:
1. **Header Icon**: Click the PDF icon in the top navigation bar
2. **Footer Link**: A "View PDF Version" link appears at the bottom of each article

The PDFs include:
- The custom "Weaver's Journal" header with serif typography
- Properly formatted sidenotes and margin figures
- Zebra-striped tables for readability
- High-contrast black text optimized for printing

<Sidenote>
The PDF generation uses Puppeteer to render pages with print media styles, ensuring consistent output across all browsers.
</Sidenote>

### Print Directly

You can also print any page directly from your browser using `Ctrl+P` (or `Cmd+P` on Mac). The print stylesheet will activate automatically, applying the same elegant Tufte formatting.
